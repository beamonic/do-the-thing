# Fictional demo: password-reset help

This is a demonstration plan, not a recorded live success.

## Big BIG-001, revision 1

A visitor can find password-reset instructions and reach the example reset page. Use only the supplied fictional requirements. Changing account-system behavior is out of scope.

BIG-AC-01: The visitor can find and understand the supported instructions, follow the intended link, and see no invented service behavior. The issue contains the changes and verification evidence.

Interview question Q-01: What should the page say when the reset email does not arrive? If the requirements do not answer this, keep it open and block the dependent wording. Do not invent retry timing or support promises.

## Mini MINI-001, revision 1

Parent: BIG-001 revision 1, BIG-AC-01.

Task: Add the approved instructions and link to the help page. Input is the supplied requirements and existing page. Output is the changed page and its verification report.

MINI-AC-01: The rendered page matches the approved wording, its link reaches the intended example destination, and the changes and check results are available in the issue.

Reuse Q-01's answer. If task work exposes another material question, ask only that question. Escalate any shared-rule change to the Big.

## Trial sequence

1. Delegate a permitted trial issue and read its sources.
2. Conduct the interview and resolve Q-01 in the issue.
3. Store the Big, critique the plan, and store the Mini.
4. Execute the task, stop at a safe point, and save a checkpoint.
5. Resume by inspecting current instructions and artifacts.
6. Verify the Mini and record actual artifact revisions and checks.
7. Independently walk the whole Big journey, deliver evidence, and read back Linear.

The [sample completion record](../examples/completion.json) contains fictional passing checks to demonstrate the validator's format. Its `fictional://` references are deliberately not real evidence. Replace all checks with actual observations before using a real completion record. A validator pass is never proof of a live trial.
